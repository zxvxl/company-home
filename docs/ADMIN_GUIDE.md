# 虹远水利工程有限公司 - 后台操作手册

本手册面向网站运营人员，指导如何通过 CMS 后台管理网站内容。

## 登录后台

- 地址：http://你的域名:8080 （或管理员提供的地址）
- 账号：由管理员分配
- 默认管理员：admin / admin123（首次登录后请立即修改密码）

## 栏目管理（对应前台导航）

### 查看栏目
进入「内容管理」→「栏目管理」，可以看到网站所有栏目的树形结构。

### 修改栏目名称
点击栏目右侧「编辑」按钮，修改「栏目名称」字段，保存后前台导航自动更新。

### 显示/隐藏栏目
编辑栏目时，将「是否显示」设置为「否」，前台导航将不显示该栏目。

### 栏目排序
修改「排序」数字，数字越小越靠前。

## 内容管理

### 发布新闻
1. 进入「内容管理」→「新闻中心」栏目
2. 点击「新增」按钮
3. 填写标题、摘要
4. 使用富文本编辑器编写正文（支持插入图片、表格）
5. 上传封面图片
6. 选择状态「已发布」
7. 点击「保存」

### 管理工程案例
1. 进入「内容管理」→「工程案例」栏目
2. 新增案例时填写：项目名称、地点、工期、规模、详细介绍
3. 上传项目现场照片
4. 设置「置顶」可让案例在首页展示

### 修改公司信息
1. 进入「内容管理」→「关于我们」栏目
2. 编辑对应内容即可修改公司简介、发展历程等

### 管理招聘信息
1. 进入「内容管理」→「人才招聘」栏目
2. 每个岗位作为一条内容发布
3. 招满后将状态改为「下线」或删除

## 资源管理（图片/文件）

### 上传图片
1. 进入「资源管理」
2. 点击「上传」按钮选择本地图片
3. 支持批量上传
4. 上传后可在内容编辑中直接选用

### 图片要求
- 轮播图建议尺寸：1920×600 像素
- 案例封面图建议尺寸：800×500 像素
- 新闻封面图建议尺寸：600×400 像素
- 格式：JPG/PNG，单张不超过 5MB

## 系统设置

### 修改登录密码
进入「系统管理」→「个人中心」→「修改密码」

### 用户管理
管理员可在「系统管理」→「用户管理」中添加/删除后台账号。

## 常见问题

**Q: 修改内容后前台没更新？**
A: 内容修改后前台有约 5-10 分钟缓存，稍等即可自动更新。也可联系技术人员清除缓存。

**Q: 图片上传失败？**
A: 请检查图片大小（不超过 5MB）和格式（JPG/PNG）。

**Q: 忘记密码？**
A: 联系系统管理员重置密码。

**Q: 想隐藏某个页面？**
A: 在「栏目管理」中将对应栏目设为「不显示」即可。
