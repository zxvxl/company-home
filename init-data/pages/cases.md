# 工程案例

虹远水利工程有限公司成立二十一年来，累计承建各类水利工程500余项，涵盖水库大坝、河道治理、农田灌溉、防洪排涝、水土保持、城乡供水等各个领域。以下为近年来的代表性工程案例。

---

## 一、青山水库除险加固工程

<!-- 图片: 青山水库工程竣工全景 -->

| 项目信息 | 详情 |
|---------|------|
| **工程名称** | 青山水库除险加固工程 |
| **工程地点** | 青山县境内 |
| **工程规模** | 总库容1200万立方米，中型水库 |
| **建设工期** | 2022年6月 - 2024年1月 |
| **工程投资** | 4500万元 |

### 工程简介

青山水库始建于1975年，是一座以防洪、灌溉为主的中型水库。由于运行近50年，大坝出现渗漏、溢洪道老化等安全隐患，被列为省级病险水库。本次除险加固工程主要内容包括：大坝防渗加固（帷幕灌浆、坝坡培厚）、溢洪道改建（底板加固、边墙重建）、输水设施改造、大坝安全监测系统建设等。

### 技术亮点

- 创新采用"分段变压循环灌浆工法"解决断层破碎带防渗难题
- 预应力锚索与混凝土面板复合加固技术应用
- BIM技术全过程辅助施工管理
- 智能监测系统实时监控施工质量

### 工程成效

工程竣工后，水库防洪标准由50年一遇提高到100年一遇，有效保障下游3个乡镇、2.6万人的防洪安全，改善灌溉面积1.5万亩。工程质量优良率达92.3%。

## 二、清河流域综合治理工程

<!-- 图片: 清河治理工程效果图 -->

| 项目信息 | 详情 |
|---------|------|
| **工程名称** | 清河流域综合治理工程 |
| **工程地点** | 清河市区段 |
| **工程规模** | 治理河道12.6公里 |
| **建设工期** | 2023年3月 - 2024年12月 |
| **工程投资** | 2.8亿元 |

### 工程简介

清河流域综合治理工程是清河市改善城市水环境的重点民生工程。主要建设内容包括河道清淤疏浚、护岸工程、生态修复、截污管网建设、景观绿化及滨河休闲设施等，致力于将清河打造为集防洪排涝、生态廊道、休闲游憩于一体的城市滨水空间。

### 技术亮点

- "深潭-浅滩-湿地"多样化水体形态构建技术
- 生态石笼与植生挡墙柔性护岸
- 15000平方米人工湿地生态系统建设
- 智慧水利监测管理系统集成应用

### 工程成效

治理后河道水质从劣V类改善为IV类，部分河段达III类标准；建成10公里滨河绿道；恢复河流生态系统，已观测到白鹭、翠鸟等多种水鸟栖息。

## 三、万亩灌区节水改造工程

<!-- 图片: 万亩灌区改造示意图 -->

| 项目信息 | 详情 |
|---------|------|
| **工程名称** | 万亩灌区节水改造工程 |
| **工程地点** | 红星镇及周边三个乡镇 |
| **工程规模** | 灌溉面积1.2万亩 |
| **建设工期** | 2024年1月 - 2025年6月 |
| **工程投资** | 1.2亿元 |

### 工程简介

万亩灌区始建于上世纪六十年代，渠系老化严重，灌溉水利用系数仅为0.42。本次改造主要内容包括：改造干渠15.6公里、支渠42.3公里；新建渠系建筑物186座；配套量水设施68处；改造泵站3座；建设灌区信息化管理系统一套。

### 技术亮点

- 因地制宜的多元化渠道防渗方案
- 灌区信息化精准计量与远程调度系统
- 生态廊道设计保留动物通道
- 多标段平行交叉施工组织模式

### 工程成效

建成后灌溉水利用系数将提至0.65以上，年节水量约800万立方米，有效灌溉面积恢复至1.2万亩，惠及12000余户农户，预计年增收2000万元。

## 四、城区防洪堤建设工程

<!-- 图片: 城区防洪堤全景 -->

| 项目信息 | 详情 |
|---------|------|
| **工程名称** | 虹城市城区防洪堤建设工程 |
| **工程地点** | 虹城市城区段 |
| **工程规模** | 防洪堤8.5公里，设防标准50年一遇 |
| **建设工期** | 2020年9月 - 2023年6月 |
| **工程投资** | 3.6亿元 |

### 工程简介

虹城市城区防洪堤建设工程是市级重点民生水利工程，主要建设内容包括新建防洪堤8.5公里、护岸工程、排涝泵站3座、穿堤建筑物12座及滨河景观绿化工程。工程集防洪、排涝、生态、景观于一体，是一项综合性城市水利工程。

### 技术亮点

- "样板引路"和"首件验收"质量管理模式
- 生态护坡技术融入防洪堤设计
- 智能化监测预警系统实时守护安全
- 软土地基处理核心技术应用

### 工程成效

有效保护城区12万居民防洪安全，2023年汛期成功抵御超标准洪水。沿堤建成10公里滨河绿道，成为市民休闲健身热门场所。该工程荣获省级水利工程质量最高奖"禹王奖"。

## 五、东部新城供水管网工程

<!-- 图片: 供水管网工程施工现场 -->

| 项目信息 | 详情 |
|---------|------|
| **工程名称** | 东部新城供水管网工程 |
| **工程地点** | 虹城市东部新城 |
| **工程规模** | 管线总长45公里，日供水能力5万立方米 |
| **建设工期** | 2021年4月 - 2022年12月 |
| **工程投资** | 1.8亿元 |

### 工程简介

东部新城供水管网工程是配套新城开发建设的重要市政基础设施项目。主要建设内容包括：DN1200输水主管线8公里、DN300~DN800配水管网37公里、加压泵站2座、调蓄水池1座（容积5000立方米）及供水自动化控制系统。

### 技术亮点

- 大口径球墨铸铁管道非开挖穿越技术
- 供水管网水力模型优化设计
- SCADA自动化监控与调度系统
- 管道防腐与漏损控制技术

### 工程成效

工程建成后日供水能力达5万立方米，满足东部新城20万居民及工业园区用水需求。管网漏损率控制在8%以下，供水水质全部达到国家饮用水卫生标准。

## 六、山地水土保持示范工程

<!-- 图片: 南岭山区水保工程治理效果 -->

| 项目信息 | 详情 |
|---------|------|
| **工程名称** | 南岭山区水土保持示范工程 |
| **工程地点** | 南岭山区 |
| **工程规模** | 治理面积15平方公里 |
| **建设工期** | 2022年1月 - 2023年8月 |
| **工程投资** | 6800万元 |

### 工程简介

南岭山区水土保持示范工程是省级水土保持重点治理项目，治理区位于南岭山区水土流失严重区域。主要建设内容包括：坡面治理工程（梯田建设500亩、经果林种植2000亩）、沟道治理工程（拦沙坝15座、谷坊32座）、封禁治理8平方公里、水保监测站点建设等。

### 技术亮点

- 小流域综合治理系统规划方法
- 生物措施与工程措施有机结合
- GIS遥感技术辅助水土流失动态监测
- 乡土植物为主的生态恢复方案
- 崩岗治理创新技术应用

### 工程成效

治理区植被覆盖率从32%提高到68%，年土壤侵蚀量减少85%以上。建成经果林2000亩，每年为当地农民增收约500万元。该工程被评为省级水土保持示范工程，多次接待省内外同行参观学习。
