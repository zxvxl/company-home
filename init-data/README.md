# 数据初始化指南

## 目录说明

`init-data` 目录包含虹远水利工程有限公司官方网站的所有初始化内容数据，包括新闻文章、静态页面等。这些数据用于在 Halo 后台管理系统中快速搭建网站内容，确保网站上线时即拥有完整的展示内容。

## 目录结构

```
init-data/
├── README.md          # 本说明文件
├── posts/             # 新闻文章（按编号排序）
│   ├── 001-water-reservoir-completion.md
│   ├── 002-flood-control-award.md
│   ├── 003-irrigation-project-start.md
│   ├── 004-safety-production.md
│   ├── 005-tech-innovation.md
│   └── 006-river-treatment.md
└── pages/             # 静态页面
    ├── about.md
    ├── business.md
    ├── cases.md
    └── contact.md
```

## 数据导入步骤

请按照以下步骤将数据导入 Halo 管理后台：

### 第一步：创建文章分类

登录 Halo 管理后台，进入「文章」→「分类」，依次创建以下分类：

| 分类名称 | 别名（slug） | 说明 |
|---------|-------------|------|
| 公司动态 | company-news | 公司内部新闻、荣誉、活动等 |
| 行业新闻 | industry-news | 水利行业政策、趋势、资讯 |
| 项目进展 | project-progress | 在建/完工项目动态报道 |
| 技术分享 | tech-sharing | 技术创新、工法研究、学术交流 |

### 第二步：创建文章

1. 进入「文章」→「写文章」
2. 打开 `posts/` 目录下的 Markdown 文件
3. 将 frontmatter 中的 `title` 填入标题栏
4. 将 frontmatter 中的 `date` 设置为发布日期
5. 选择对应的 `category` 分类
6. 添加 `tags` 中列出的标签
7. 将 `excerpt` 填入文章摘要
8. 将正文内容粘贴到编辑器中
9. 点击「发布」

建议按文件编号顺序（001-006）依次导入。

### 第三步：创建独立页面

1. 进入「页面」→「新建页面」
2. 打开 `pages/` 目录下的 Markdown 文件
3. 按照文件中的内容结构填写页面
4. 设置页面别名（slug）：
   - about.md → `/about`
   - business.md → `/business`
   - cases.md → `/cases`
   - contact.md → `/contact`
5. 发布页面

### 第四步：配置导航菜单

在「外观」→「菜单」中创建主导航菜单，添加以下菜单项：

| 菜单名称 | 链接地址 | 排序 |
|---------|---------|------|
| 首页 | / | 1 |
| 关于我们 | /about | 2 |
| 业务领域 | /business | 3 |
| 工程案例 | /cases | 4 |
| 新闻中心 | /archives | 5 |
| 联系我们 | /contact | 6 |

### 第五步：检查与调整

1. 访问网站前台，检查所有页面是否正常显示
2. 确认文章分类筛选功能正常
3. 检查导航菜单链接是否正确
4. 调整文章发布时间，确保排序合理

## 文件命名规范

- **文章文件**：`{序号}-{英文简述}.md`，例如 `001-water-reservoir-completion.md`
- **页面文件**：`{页面功能}.md`，例如 `about.md`
- 序号使用三位数字，便于排序和后续扩展
- 英文简述使用小写字母和连字符

## 图片占位说明

文件中标注 `[图片占位]` 或 `<!-- 图片: 描述 -->` 的位置需要在实际部署时替换为真实图片。建议：

1. 将图片上传至 Halo 后台的「附件」管理中
2. 获取图片链接后替换文中的占位标记
3. 推荐图片尺寸：
   - 文章封面图：1200×675px（16:9）
   - 页面横幅图：1920×600px
   - 案例缩略图：800×600px（4:3）
   - 团队照片：400×400px（1:1）
4. 图片格式建议使用 WebP 或 JPG，文件大小控制在 500KB 以内

## 注意事项

- 所有内容均为模拟数据，公司名称、项目数据等均为虚构
- 实际使用时请根据真实信息进行修改
- 联系方式、地址等信息需替换为真实数据
- 建议在正式上线前进行内容审核
