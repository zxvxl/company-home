- 丰富的后台配置选项

## 安装方法

### 方式一：后台上传安装

1. 将主题文件夹打包为 ZIP 文件
2. 登录 Halo 管理后台
3. 进入「外观」>「主题」
4. 点击右上角「安装」按钮
5. 选择打包好的 ZIP 文件上传
6. 安装完成后点击「启用」

### 方式二：手动安装

1. 将 `theme-engineering-company` 文件夹复制到 Halo 的 `themes` 目录下
2. 在后台「外观」>「主题」中找到该主题
3. 点击「启用」

## 配置指南

启用主题后，在「外观」>「主题设置」中可以配置以下选项：

### 基本设置

| 选项 | 说明 |
|------|------|
| 公司名称 | 网站标题，显示在导航栏和页脚 |
| Logo地址 | 公司 Logo 图片的 URL |
| Favicon地址 | 浏览器标签页图标 |
| 公司标语 | 首页等位置显示的标语 |
| ICP备案号 | 网站底部显示的备案信息 |

### 联系方式

| 选项 | 说明 |
|------|------|
| 公司地址 | 显示在页脚联系信息中 |
| 联系电话 | 顶部信息栏和页脚显示 |
| 电子邮箱 | 顶部信息栏和页脚显示 |
| 传真号码 | 页脚显示（可选） |
| 微信二维码 | 页脚显示的公众号二维码图片 |
| 工作时间 | 顶部信息栏显示 |

### 首页设置

| 选项 | 说明 |
|------|------|
| Banner图片1-3 | 首页轮播图的背景图片 URL |
| Banner标题1-3 | 轮播图上的主标题文字 |
| Banner副标题1-3 | 轮播图上的副标题文字 |
| 统计数字 | 完工项目、服务年限等数字 |
| 显示合作伙伴 | 是否显示合作伙伴区域 |

### SEO设置

| 选项 | 说明 |
|------|------|
| 网站关键词 | meta keywords，逗号分隔 |
| 网站描述 | meta description |
| 统计分析代码 | 百度统计或其他第三方代码 |

### 社交媒体

| 选项 | 说明 |
|------|------|
| 微信公众号 | 公众号名称或ID |
| 微博链接 | 新浪微博主页 URL |

## 模板结构

```
theme-engineering-company/
├── theme.yaml              # 主题配置文件
├── settings.yaml           # 主题设置定义
├── README.md               # 说明文档
├── templates/
│   ├── index.html          # 首页模板
│   ├── post.html           # 文章详情页
│   ├── page.html           # 自定义页面
│   ├── archives.html       # 文章归档/列表页
│   ├── categories.html     # 分类列表页
│   ├── tags.html           # 标签云页面
│   └── modules/
│       ├── header.html     # 页头片段
│       └── footer.html     # 页脚片段
└── assets/
    ├── css/
    │   └── style.css       # 主样式表
    └── js/
        └── main.js         # 主脚本文件
```

## 页面说明

| 模板 | 用途 |
|------|------|
| index.html | 首页，包含轮播、业务、统计、案例、新闻等完整区块 |
| page.html | 通用页面模板，适用于「关于我们」「联系我们」等自定义页面 |
| post.html | 新闻文章详情页，包含面包屑、文章内容、标签、上下篇导航 |
| archives.html | 新闻中心列表页，含分类筛选和分页 |
| categories.html | 分类页面，展示所有文章分类 |
| tags.html | 标签云页面，展示所有标签 |

## 自定义提示

### 修改配色方案

编辑 `assets/css/style.css` 文件顶部的 CSS 变量：

```css
:root {
  --primary: #1a5276;       /* 主色调（深蓝） */
  --primary-light: #2980b9; /* 浅主色调 */
  --accent: #e67e22;        /* 强调色（工程橙） */
  --water-teal: #1abc9c;    /* 水利蓝绿 */
}
```

### 添加新页面

1. 在 Halo 后台「页面」中创建新页面
2. 页面将自动使用 `page.html` 模板渲染
3. 在导航菜单中添加对应链接

### 菜单配置

默认导航菜单包含：首页、关于我们、业务领域、工程案例、新闻中心、联系我们。如需修改，编辑 `header.html` 中的菜单项，或通过 Halo 后台菜单管理功能进行动态配置。
